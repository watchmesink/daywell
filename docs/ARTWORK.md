# Ocean sunset

The sunset artwork is a halftone render of **ocean sunset** by **bas3line**, from [ascii.rest](https://ascii.rest/ocean-sunset/).

- Upstream source: <https://github.com/bas3line/ascii/blob/main/src/pieces/ocean-sunset.ts>
- License: MIT, Copyright (c) 2026 bas3line. The complete notice is in `Shared/AsciiRest-LICENSE.txt` and is bundled with the main app and shield extension.
- The upstream source is retained in `scripts/vendor/ascii-rest/ocean-sunset.ts`.
- Regenerate the static image with `python3 scripts/make-ocean-art.py` (Node 22.13+ and Pillow). The script renders the scene at eight seconds using palette-colored dots, without browser or network access.
- Regenerate the original dark animation with `node scripts/make-ocean-animation.mjs` (Node 22.13+ and FFmpeg). It renders the same scene into a silent 1200×600 H.264 video at 15 frames per second. The 29-second loop blends its last second into the start for a smooth repeat. Native AVPlayer playback avoids continuously computing the scene on the phone. No web view, network access, audio session, or third-party runtime is needed.

Generate the light-theme video and fallback with `node scripts/make-ocean-animation.mjs --light`. This separate variant uses warm peach/lavender paper, coral and golden ink, muted blue water, and larger halftone dots in shadows. Deeper ink and a wider range of dot sizes give the clouds, shoreline, and waves more definition while keeping the pastel paper and bright sunlight. The script also updates the appearance-aware launch artwork. Runtime theme changes swap the movie and still image. The original dark movie and image are retained unchanged.

Onboarding and the dashboard show the entire animated scene at its original 2:1 proportions, from one screen edge to the other. Content keeps its own margins while the artwork has no side margins or rounded frame. A vertical mask dissolves the top 16% and bottom 26% into the page background; the center stays fully visible. Headings overlap the bottom fade, with theme-aware text and usage colors. Animation pauses when the app is inactive or the artwork is offscreen, and respects Reduce Motion. The bundled static image is the initial frame and fallback.

Both the native launch screen and initial loading view also show the scene at full width. They use the appearance-aware `LaunchArtwork` and `LaunchBackground` assets: pastel artwork with a light background in light mode, and the original sunset with its night background in dark mode. The generator bakes the same edge fades into the launch stills because native launch storyboards cannot run custom drawing code. The original dark source image, movie, and app icon remain unchanged.

The approved square crop (source coordinates 560,90–1060,590) is used for both Home Screen icon appearances. The default light icon uses the pastel sunset; the dark appearance retains the original night sunset. On iOS 18 and later, Home Screen icon appearance follows the user's Light, Dark, or Automatic icon setting. Earlier iOS versions use the default light icon. The blocking screen's image slot retains the original crop. Regenerate the icon assets with `python3 scripts/make-icon.py` after generating both sunset variants. The shield retains its system background and static icon: iOS does not expose a full-screen background-image or animated-view API for shields. Its Close button uses the semantic iOS system blue with a white label.
